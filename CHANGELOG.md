# Changelog

All notable user-visible changes to the Databag TOS application package.

## 0.1.18-1 — 2026-11-11

### Added
- First release. Databag (`balzack/databag:0.1.18`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8059 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/databagdocker/`.
